MYUZIMA — PROFESSIONAL CHICAGO DASHBOARD

1. Extract this ZIP and open the myuzima_streamlit_starter folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: python3 -m pip install -r requirements.txt
4. Run: python3 -m streamlit run app.py
5. Open http://localhost:8501 if it does not open automatically.

The original five source files are retained in data/. The new app has five pages:
Overview, Neighborhoods, Healthcare access, Hospital finances, Data & methods.

IMPORTANT: Hospital finance figures are hospital-wide, not gunshot-specific.
The hospital finance page includes only Chicago-located hospitals in the starter
hospital file. The healthcare access page can show suburban trauma destinations.
Estimated travel time is not measured ambulance response time.
All values should be validated against primary sources before client publication.
